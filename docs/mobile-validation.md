- 自动检查：日志 10000 条时界面最多 200 条记录 + 100 条分组上下文；全量搜索/复制、分页、暂停、清空、淘汰、移除后取消渲染、更多菜单的 Escape 和关闭行为均有回归测试。

## 建议验证环境

分别记录 Android Chrome、Android System WebView、iOS Safari、WKWebView。填写设备型号、系统版本、WebView/浏览器版本、页面协议、是否嵌在原生应用内。

手机不能把电脑的 127.0.0.1 当作电脑地址。使用受控的测试地址或项目已有的设备转发方式。HTTP 下的剪贴板能力与 HTTPS 可能不同，请分别记录；未经明确安排不要向设备安装测试应用。

## 新增验收项（待测）

- 异常「查看前后记录」进入 ±30 秒时间线；清除范围后可查看全部保留记录。
- 网络 10000 条时翻页和详情更新不丢失滚动位置；搜索仍能命中未挂载的请求。
- 存储 JSON 错误时不保存；取消和失焦不写入；删除确认可取消。
- 在业务页面创建 WebSocket/EventSource，验证发送、接收、SSE 命名事件和关闭；关闭采集/销毁面板不应断开业务连接。
- 原生实现 onExport，分别验证 HTML/JSON 文件名、UTF-8 中文内容、真实保存回执、用户取消、失败重试，以及消息过大时的业务桥接处理。
- 长任务不支持时无数据，不把缺少记录误判为页面没有卡顿；关注开启面板自身开销。

## 导出与降级补充验收（待测）

- 原生回调长时间不回执时，30 秒后提示；关闭重开仍防重复，确认取消等待明确不等于取消保存。先前任务的迟到回执不能影响新任务。
- 中文大报告按 UTF-8 字节计量，超过 5 MiB 不发送；HTML 转义放大时也拒绝，JSON 较小时仍可导出。
- 一键清空后旧预览关闭、诊断记录清空，业务 Cookie/存储与连接保持正常。
- 宿主保护某个采集接口时该通道停用，其余面板可用；解除保护后从设置重试。

测试页的“模拟成功”只返回 Promise，不发送原生保存消息，不代表文件落盘。等待超时、取消等待、旋转、后台恢复、大数据长时运行及物理设备仍待验收。宿主自身存在离线/API 连接提示，不属于本次组件测试结果。
