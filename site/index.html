CONFIGURATION
初始化参数，一次看清。
完整说明与示例 ↗
所有参数均可省略。默认收起面板，初始化时开始采集。
参数类型默认值说明
theme'light' / 'dark' / 'auto''auto'面板主题；auto 跟随系统配色变化。
lang'zh' / 'en'自动检测读取 navigator.language，以 zh 开头时用中文，其余用英文。
defaultPluginsBuiltinPlugin[]['network', 'element', 'storage', 'system']按数组顺序添加网络、元素、存储、系统面板；重复项去重，未知项忽略。传 [] 只保留日志面板。
maxLogNumbernumber1000保留的日志记录数上限，超出后淘汰最早记录；不是字节大小限制。
maxNetworkNumbernumber200保留的网络请求记录数上限，超出后淘汰最早记录。
entryButtonbooleantrue是否显示悬浮入口。false 时仍可通过实例的 show() 或 showTab() 打开。
exportEnabledbooleantrue是否显示日志工具栏的导出入口。false 同时隐藏报告预览内的复制与下载入口；getReport() 仍可调用，日志自身的复制工具不受影响。
targetHTMLElement / string / nullnull → document.body挂载节点或 CSS 选择器。挂载时选择器必须匹配 HTMLElement，否则报错；省略或传 null 使用 body。
onReady() => voidundefined界面挂载完成后执行一次，无参数；不代表页面资源或请求加载完成。
数量上限建议传正整数；小数向下取整，至少保留 1 条。初始化时 0、负数或非有限数字回退默认值。隐藏面板、入口或导出不会停止采集，结束调试请调用 destroy()。
onReady 可能同步执行，请通过 GravScope.current 访问实例。运行时 setOption() 仅支持 theme、maxLogNumber、maxNetworkNumber；其他初始化设置需销毁后重建。


API REFERENCE
方法、参数和返回值。
完整 API 与插件文档 ↗
以下示例假设已创建 const panel = new GravScope()。所有方法同步执行；void 表示无返回值，不支持链式调用。
show()
参数：无。
返回值：void
打开面板并清除未读数量，不清空日志。
panel.show();
hide()
参数：无。
返回值：void
收起面板；采集继续进行。
panel.hide();
showTab(id)
参数：id: string，已添加的面板 ID。
返回值：void
切换并打开面板。内置 ID 为 log、network、element、storage、system；自定义面板用 plugin.id。ID 不存在时保留当前标签，但仍打开面板。
panel.showTab('network');
setOption(key, value)
参数：key: 'theme'，value: 'light' / 'dark' / 'auto'；或 key: 'maxLogNumber' / 'maxNetworkNumber'，value: number。
返回值：void
即时修改主题或容量。运行时容量向下取整并至少为 1；非有限值忽略（不同于初始化回退默认值）。非法主题忽略。仅支持列出的三个 key；调低容量立即淘汰旧记录。
panel.setOption('theme', 'dark');
panel.setOption('maxLogNumber', 500);
panel.setOption('maxNetworkNumber', 100);
setSystemInfo(key, value)
参数：key: string，信息名称；value: string，显示内容。
返回值：void
添加或覆盖同名自定义系统信息，进入报告的 custom 字段；不需要先打开系统面板。
panel.setSystemInfo('Build', '2026.11.04');
panel.setSystemInfo('Environment', 'staging');
getReport(options?)
参数：options?: ReportOptions，默认 {}；字段见下表。
返回值：DiagnosticReport
同步返回脱敏快照，不下载、不上传，也不打开报告窗口。exportEnabled 为 false 时仍可调用。since 非有限或小于 0 时抛出错误。
const report = panel.getReport({
  since: Date.now() - 5 * 60 * 1000,
  includeBodies: false,
});
const json = JSON.stringify(report, null, 2);
addPlugin(plugin)
参数：plugin: GravScopePlugin，已经配置事件和工具的插件实例。
返回值：void
添加标签并同步触发 init、render。ID 必须唯一，与现有内置或自定义插件重名会抛错。添加后不会自动切换过去。
const plugin = new GravScope.Plugin('build', 'Build');
plugin.on('render', element => {
  element.textContent = 'Build 2026.11.04';
});
panel.addPlugin(plugin);
panel.showTab('build');
removePlugin(id)
参数：id: string，要移除的插件 ID。
返回值：void
触发 remove 并移除标签；ID 不存在则不操作。移除当前标签会切换到第一个剩余标签。插件 remove 回调抛错时仍移除标签，但异常会传给调用方。移除网络标签不停止网络采集。
panel.removePlugin('build');
destroy()
参数：无。
返回值：void
移除界面，触发插件 remove，释放实例持有的采集钩子与监听，清空 GravScope.current。可重复调用；插件清理异常不会阻断销毁。实例不可重新启用，需要 new 创建新实例。
panel.destroy();
const nextPanel = new GravScope();
getReport 参数与返回结构
since: number，默认 0。Unix 毫秒时间戳，包含该时刻及之后的日志与请求（按请求开始时间）；不是秒，也不是持续时长。
includeBodies: boolean，默认 false。是否包含已采集的请求体与响应体；仍受采集截断和脱敏限制，不会补抓此前未采集的内容。
schemaVersion: 1：报告结构版本。
version: string：GravScope 库版本。
createdAt: string：生成时间，ISO 8601 字符串。
page: string：脱敏后的当前页面 URL。
device: { userAgent: string; language: string; viewport: string }：浏览器、语言与视口信息。
custom: unknown：脱敏后的自定义系统信息。
logs: unknown[]：符合时间范围且仍保留的日志。
network: unknown[]：符合时间范围且仍保留的请求。
policy: string：采集和脱敏边界说明。
字段内容经过脱敏和截断，不应当作原始对象；请在 destroy() 前取得报告。
公开属性与插件 API
GravScope.current 是当前实例或 null；GravScope.version 与 panel.version 是只读版本字符串；GravScope.Plugin 是插件构造函数。
new GravScopePlugin(id, name)
id: string，非空唯一标识；name: string，标签名称，空字符串时使用 id。
返回：GravScopePlugin
const plugin = new GravScope.Plugin('build', 'Build');
on(event, handler)
event 为下表事件名；handler 为对应回调。添加监听，不覆盖已有回调。
返回：this
plugin.on('render', element => { element.textContent = 'Ready'; });
addTool(name, onClick)
name: string，按钮文字；onClick: () => void，点击回调，无参数。
返回：this
plugin.addTool('Refresh', () => console.info('Refresh requested'));
getTools()
无。返回工具数组的浅拷贝；按钮对象本身仍共享，不应修改它们。
返回：Array<{ name: string; onClick: () => void }>
const labels = plugin.getTools().map(tool => tool.name);
emit(event, ...args)
event 为事件名；render 需要 HTMLElement，其余无参数。同步按注册顺序执行，回调抛错会中断并向外传播。通常由面板调度，手动调用不会切换 UI。
返回：void
// Manual handler invocation only; does not open the tab.
plugin.emit('show');
init — () => void：插件添加时执行，先于 render。
render — (element: HTMLElement) => void：插件添加时执行，用 element 填充面板内容。
show — () => void：标签激活或面板 show 时触发；可能重复触发，不保证只在真正可见时执行。
hide — () => void：切换离开当前标签或调用 hide 时触发；可能重复。
remove — () => void：removePlugin 或 destroy 时清理定时器、事件等自有资源。
请在 addPlugin() 前注册回调和工具。id、name 为只读字符串，空 id 会抛错。on 与 addTool 返回插件自身，支持链式调用。getTools 返回浅拷贝。没有 off() 方法，自有监听和定时器请在 remove 中清理。工具栏在标签激活时读取工具列表，追加工具不会立即重绘。

配置面板与插件
支持浅色、深色、跟随系统，以及中英文。日志默认启用，可配置其他面板；隐藏网络面板不会关闭底层网络采集。通过 GravScopePlugin 添加自己的工具。
new GravScope({
  theme: 'auto', lang: 'zh',
  maxLogNumber: 1000,
  maxNetworkNumber: 200
});
导出的报告包含什么？
已保留的日志、请求与设备信息。请求体和响应体默认排除；不含本地存储和命令源码。常见凭证字段与 URL 参数值会被遮蔽，但无法识别所有业务敏感信息。对象值取导出时的状态，报告不是会话录制。
const report = panel.getReport({
  since: Date.now() - 5 * 60 * 1000,
  includeBodies: false
});
网络预览与浏览器支持
fetch 响应预览最多读取约 100 KB，SSE 响应体不缓存。跨域响应的可见性仍受浏览器规则限制。真机兼容性、长时间性能与移动端下载仍在验证中；请先在目标设备试用。
安全使用与反馈
命令行会在当前页面执行 JavaScript，请勿面向终端用户默认启用。GravScope 的诊断报告不会由工具自动上传；本演示的点击操作会访问本站静态资源，并可写入示例本地存储。
