所有参数均可省略。默认收起面板，初始化时开始采集。
参数类型默认值说明
theme'light' / 'dark' / 'auto''auto'面板主题；auto 跟随系统配色变化。
lang'zh' / 'en'自动检测读取 navigator.language，以 zh 开头时用中文，其余用英文。
defaultPluginsBuiltinPlugin[]['network', 'errors', 'element', 'storage', 'system', 'timeline', 'performance', 'streams']按数组顺序添加网络、异常、元素、存储、系统、时间线、性能、实时连接面板；重复项去重，未知项忽略。传 [] 只保留日志面板。

exportEnabledbooleantrue是否显示日志工具栏的导出入口。false 同时隐藏报告预览内的复制与下载入口；getReport() 仍可调用，日志自身的复制工具不受影响。

onExport(file: ExportFile) => void | Promise<void>undefined接管 HTML/JSON 导出；初始化配置，参数和回执约定见下方原生导出说明。
targetHTMLElement / string / nullnull → document.body挂载节点或 CSS 选择器。挂载时选择器必须匹配 HTMLElement，否则报错；省略或传 null 使用 body。

API REFERENCE
方法、参数和返回值。
完整 API 与插件文档 ↗
以下示例假设已创建 const panel = new GravScope()。所有方法同步执行；void 表示无返回值，不支持链式调用。
show()
参数：无。
返回值：void
打开面板并清除未读数量，不清空日志。
panel.show();
hide()
参数：无。
返回值：void
收起面板；采集继续进行。
panel.hide();
showTab(id)
参数：id: string，已添加的面板 ID。
返回值：void
切换并打开面板。内置 ID 为 log、network、errors、element、storage、system、timeline、performance、streams；自定义面板用 plugin.id。ID 不存在时保留当前标签，但仍打开面板。
panel.showTab('network');
setOption(key, value)
参数：key: 'theme'，value: 'light' / 'dark' / 'auto'；或 key: 'maxLogNumber' / 'maxNetworkNumber'，value: number。 或 key: 'entryButton'，value: boolean。
返回值：void
即时修改主题、容量或悬浮入口。运行时容量向下取整并至少为 1；非有限值忽略（不同于初始化回退默认值）。非法主题忽略。0.2.0 另支持 preserveLogs（boolean）和 capture（Partial<CaptureOptions>），以及 networkIgnore / redactKeys（string[]）；调低容量立即淘汰旧记录。entryButton 的运行时修改从 0.1.2 开始支持。false 立即隐藏悬浮按钮；true 在面板收起时显示按钮，面板打开时仍隐藏。设置不会收起面板或停止采集，非布尔值忽略。
panel.setOption('theme', 'dark');
panel.setOption('maxLogNumber', 500);
panel.setOption('maxNetworkNumber', 100);
// 隐藏 / 恢复悬浮入口
panel.setOption('entryButton', false);
panel.setOption('entryButton', true);
setSystemInfo(key, value)
参数：key: string，信息名称；value: string，显示内容。
返回值：void
添加或覆盖同名自定义系统信息，进入报告的 custom 字段；不需要先打开系统面板。
panel.setSystemInfo('Build', '2026.11.04');
panel.setSystemInfo('Environment', 'staging');
getReport(options?)
参数：options?: ReportOptions，默认 {}；字段见下表。
返回值：DiagnosticReport
同步返回脱敏快照，不下载、不上传，也不打开报告窗口。exportEnabled 为 false 时仍可调用。since 非有限或小于 0 时抛出错误。
const report = panel.getReport({
  since: Date.now() - 5 * 60 * 1000,
  includeBodies: false,
});
const json = JSON.stringify(report, null, 2);
addPlugin(plugin)
参数：plugin: GravScopePlugin，已经配置事件和工具的插件实例。
返回值：void
添加标签并同步触发 init、render。ID 必须唯一，与现有内置或自定义插件重名会抛错。添加后不会自动切换过去。
const plugin = new GravScope.Plugin('build', 'Build');
plugin.on('render', element => {
  element.textContent = 'Build 2026.11.04';
});
panel.addPlugin(plugin);
panel.showTab('build');
removePlugin(id)
参数：id: string，要移除的插件 ID。
返回值：void
触发 remove 并移除标签；ID 不存在则不操作。移除当前标签会切换到第一个剩余标签。插件 remove 回调抛错时仍移除标签，但异常会传给调用方。移除网络标签不停止网络采集。
panel.removePlugin('build');
destroy()
参数：无。
返回值：void
移除界面，触发插件 remove，释放实例持有的采集钩子与监听，清空 GravScope.current。可重复调用；插件清理异常不会阻断销毁。实例不可重新启用，需要 new 创建新实例。
panel.destroy();
const nextPanel = new GravScope();
getReport 参数与返回结构
since: number，默认 0。Unix 毫秒时间戳，包含该时刻及之后的日志与请求（按请求开始时间）；不是秒，也不是持续时长。
includeBodies: boolean，默认 false。是否包含已采集的请求体与响应体；仍受采集截断和脱敏限制，不会补抓此前未采集的内容。
schemaVersion: 1：报告结构版本。
version: string：GravScope 库版本。
createdAt: string：生成时间，ISO 8601 字符串。
page: string：脱敏后的当前页面 URL。
device: { userAgent: string; language: string; viewport: string }：浏览器、语言与视口信息。
custom: unknown：脱敏后的自定义系统信息。
logs: unknown[]：符合时间范围且仍保留的日志。
network: unknown[]：符合时间范围且仍保留的请求。
policy: string：采集和脱敏边界说明。
字段内容经过脱敏和截断，不应当作原始对象；请在 destroy() 前取得报告。
公开属性与插件 API
GravScope.current 是当前实例或 null；GravScope.version 与 panel.version 是只读版本字符串；GravScope.Plugin 是插件构造函数。
new GravScopePlugin(id, name)
id: string，非空唯一标识；name: string，标签名称，空字符串时使用 id。
返回：GravScopePlugin
const plugin = new GravScope.Plugin('build', 'Build');
on(event, handler)
event 为下表事件名；handler 为对应回调。添加监听，不覆盖已有回调。
返回：this
plugin.on('render', element => { element.textContent = 'Ready'; });
addTool(name, onClick)
name: string，按钮文字；onClick: () => void，点击回调，无参数。
返回：this
plugin.addTool('Refresh', () => console.info('Refresh requested'));
getTools()
无。返回工具数组的浅拷贝；按钮对象本身仍共享，不应修改它们。
返回：Array<{ name: string; onClick: () => void }>
const labels = plugin.getTools().map(tool => tool.name);
emit(event, ...args)
event 为事件名；render 需要 HTMLElement，其余无参数。同步按注册顺序执行，回调抛错会中断并向外传播。通常由面板调度，手动调用不会切换 UI。
返回：void
// Manual handler invocation only; does not open the tab.
plugin.emit('show');
init — () => void：插件添加时执行，先于 render。
render — (element: HTMLElement) => void：插件添加时执行，用 element 填充面板内容。
show — () => void：标签激活或面板 show 时触发；可能重复触发，不保证只在真正可见时执行。
hide — () => void：切换离开当前标签或调用 hide 时触发；可能重复。
remove — () => void：removePlugin 或 destroy 时清理定时器、事件等自有资源。
请在 addPlugin() 前注册回调和工具。id、name 为只读字符串，空 id 会抛错。on 与 addTool 返回插件自身，支持链式调用。getTools 返回浅拷贝。没有 off() 方法，自有监听和定时器请在 remove 中清理。工具栏在标签激活时读取工具列表，追加工具不会立即重绘。


调试流程增强（0.2.0）
日志工具栏保留清空、暂停滚动、最新，其余操作放入「更多」。大量日志每页显示 200 条，加最多 100 条分组上下文；搜索与复制覆盖全部保留记录。
网络面板新增方法与精确状态码 / 状态段筛选，以及 cURL 复制。日志可暂停滚动，查看新增条数后恢复跟随。新增 errors 异常面板，聚合 JS、Promise、资源加载及 Console 错误。
日志工具栏的「采集设置」可独立启停 Console、Network、Errors，也可调用 setOption('capture', { network: false })。关闭不会删除已有记录或取消页面请求；重新开启后记录新活动。这些功能从 0.2.0 提供，报告回放也兼容 0.1.2 的 JSON。


原生导出接入与诊断增强（0.2.0）


新增 timeline 时间线、performance 性能、streams 实时连接面板。异常可查看前后各 30 秒的日志与请求；网络每页 100 条，存储支持搜索、JSON 格式化与校验、明确保存和删除确认。性能汇总慢请求、已知大小排行及浏览器支持的长任务。


capture 新增 navigation、performance、realtime 三个开关。实时采集观察新建 WebSocket / EventSource、默认消息及业务注册的命名 SSE 事件；每条文本最多 2000 字符，活动共享最近 1000 条上限。不会关闭业务连接；fetch 读取的 SSE 正文仍不缓冲。


panel.setOption('networkIgnore', ['/heartbeat', '/analytics']);
panel.setOption('redactKeys', ['phone', 'customerId']);
panel.setOption('capture', { realtime: false });


networkIgnore 按区分大小写的 URL 子串排除后续请求与新连接；redactKeys 按忽略大小写的完整字段名脱敏报告与存档，不修改原始记录。两个数组均为替换规则，每项 1–100 字符，最多 100 项。


onExport(file)：由宿主保存或分享


仅初始化配置，类型为 (file: ExportFile) => void | Promise<void>。点击 HTML/JSON 导出按钮时触发；复制、全选和 getReport() 不触发。从 0.2.0 提供。


参数字段说明
requestId本次接管任务编号，可交给原生关联回执
filenamegravscope-报告时间.html / .json，已包含后缀
mimeTypetext/html;charset=utf-8 或 application/json;charset=utf-8
formathtml / json
content脱敏后的文本，不是 Blob、文件路径或 Base64


new GravScope({
  async onExport(file) {
    // appBridge 由业务 App 提供；Promise 在原生操作完成后 resolve/reject。
    await window.appBridge.saveDiagnosticFile({
      requestId: file.requestId,
      filename: file.filename,
      mimeType: file.mimeType,
      content: file.content
    });
  }
});


不配置时仍通过 Blob 发起浏览器下载。配置后完全接管导出，不再自动下载；实例级任务等待时禁用导出按钮，关闭再打开仍然防重复，并显示任务编号与文件名。30 秒后显示等待提示；确认「取消等待」仅停止组件等待，原生操作可能仍在进行，再次导出可能重复。旧回执不会覆盖新任务。抛错或拒绝时显示失败、允许重试和复制，不自动回退下载。关闭对话框不会取消原生操作；组件不会把回调完成当成文件已保存。


原生端负责 UTF-8 编码、文件保存/分享和回执。仅发送 postMessage 不等于保存成功；桥接消息大小限制、分块、上传和取消均由业务实现。文件后缀帮助识别，但不能代替 WebView 的下载能力。exportEnabled: false 只隐藏导出界面，getReport() 仍可用。


清空与可靠性（0.2.0）
panel.clearAll(): void 无参数，清空日志、请求、活动、自定义系统信息与历史存档内容，并关闭旧报告预览。保留采集/历史开关、业务存储和连接，不取消已交给原生的导出。更多菜单入口需确认，API 直接执行；destroy 后无操作。
JSON 预览显示 UTF-8 字节大小，JSON/HTML 导出上限均为 5 MiB；HTML 转义后再次检查。getReport() 也限制报告大小与筛选后各 10000 条日志/请求，超限抛出 name 为 ReportLimitError 的错误；不截断、不调用导出回调，可缩小时间范围或排除正文后重试。
采集接口受保护时按通道回滚、停用并提示，不阻断其他面板；采集设置支持重试。日志对象按引用保留，展开和导出时的值可能已变化。


采集状态（0.2.0）
panel.getCaptureStatus() 无参数，返回六通道状态副本，每项含 enabled、state、detail。state 为 enabled / disabled / unavailable / failed，区分采集中、已停用、环境不支持和启用失败；修改副本不改变配置，destroy 后返回停用状态。
const status = panel.getCaptureStatus();
// 支持不足时，没有记录不代表没有发生问题。
console.log(status.performance.state, status.performance.detail);
面板显示采集状态，采集设置提供详细覆盖范围；实时面板明确仅观察新建连接。官网实验台使用 0.2.2。


刷新后保留日志（0.2.0）
日志筛选栏开启「保留日志」，或初始化传 preserveLogs: true。支持 setOption('preserveLogs', true / false) 动态控制。从 0.2.0 提供。
使用当前标签页的同源 sessionStorage，默认关闭，开启后记住会话偏好。最多保存 200 条脱敏静态日志，JSON 限制约 256 KiB。恢复时标记历史并分隔新会话；清空同时删除保存内容，关闭开关删除存档但保留当前显示。
不保存网络请求和命令源码；存储不可用或页面被强杀时可能无法完整恢复。

页面性能报告（0.2.1）
性能与系统面板统一展示 DNS、连接、TLS、请求/导航首字节、文档下载、DOM 就绪、Load、FP/FCP 和文档大小；支持搜索、复制和 JSON/HTML 导出，报告回放可查看 performance 字段。
const report = panel.getReport();
console.log(report.performance?.metrics.load);
value 为数值或 null；unit 为 ms / bytes；state 为 available / pending / unavailable。0 是有效观测值，不支持或未提供时不伪造数值。Load 不等于业务就绪；这些是当前文档的浏览器快照，不含标准 LCP/CLS/INP 评分，也不是 SPA 路由或 BFCache 恢复耗时。关闭长任务采集不禁止读取这些快照；清空诊断记录不会清除浏览器计时。
iframe 历史按固定框架位置隔离，并在报告中标明来源。动态增删或重排仍需谨慎，不包含跨框架日志聚合。

配置面板与插件
支持浅色、深色、跟随系统，以及中英文。日志默认启用，可配置其他面板；隐藏网络面板不会关闭底层网络采集。通过 GravScopePlugin 添加自己的工具。
new GravScope({
  theme: 'auto', lang: 'zh',
  maxLogNumber: 1000,
  maxNetworkNumber: 200
});
导出的报告包含什么？
已保留的日志、请求与设备信息。请求体和响应体默认排除；不含本地存储和命令源码。常见凭证字段与 URL 参数值会被遮蔽，但无法识别所有业务敏感信息。对象值取导出时的状态，报告不是会话录制。
const report = panel.getReport({
  since: Date.now() - 5 * 60 * 1000,
  includeBodies: false
});
网络预览与浏览器支持
fetch 响应预览最多读取约 100 KB，SSE 响应体不缓存。跨域响应的可见性仍受浏览器规则限制。真机兼容性、长时间性能与移动端下载仍在验证中；请先在目标设备试用。
